# Rai ♡ — 4 meses

Web-regalo para celebrar cuatro meses juntos.

### Contenido
- Historia y carta personalizada
- Contador en tiempo real desde el 02/06/2026
- Canción
- Galería de recuerdos con las fotos incluidas
- Álbumes de viajes
- Diseño responsive para móvil
- Visores de fotos a pantalla completa

### Publicación
La carpeta es estática y puede publicarse en Vercel, Netlify, GitHub Pages, etc.

Consulta `EDITAR.md` para modificar textos, fotos y viajes sin romper la estructura.
